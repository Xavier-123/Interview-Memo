# Interview Memo

本地优先的求职面试管理工作台。用来跟踪岗位进度、记录面试问答、复盘弱项，并把题目沉淀成个人题库。

数据全部存在浏览器 `localStorage`，无需后端、无需登录。首次打开会预置一份 Demo 数据，方便熟悉流程。

## 功能概览

- **岗位看板**：已投递 → 简历通过 → 笔试 → 一面 → 二面 → HR 面 → Offer 的 Kanban / 表格双视图，支持拖拽改状态；点击进入岗位详情页
- **多简历管理**：维护多套简历与不可变版本，记录每个岗位实际投递的版本
- **面试记录**：轮次、时间、问答、弱项、学习清单
- **日历**：月 / 周 / 日查看即将到来的面试（可配置每周起始日）
- **复盘**：面试后评分与总结，自动生成摘要
- **题库**：把面试题归档、去重、标记掌握程度；间隔复习队列
- **分析**：薄弱知识点、公司/轮次统计，可选 AI 学习建议
- **模拟面试**：基于公司/JD/简历或项目深挖的多轮 AI 模拟
- **提醒**：应用内 Toast + 可选浏览器通知
- **导入导出**：JSON 备份与迁移（严格字段校验）

## 快速开始

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

其他命令：

```bash
npm run build     # 生产构建
npm run preview   # 预览构建产物
npm run lint      # Oxlint 检查
npm test          # Vitest 单元测试
```

## 推荐使用流程

按这个顺序用，数据会自然串起来：

```
简历 / 公司 → 岗位 → 面试 → 记录问答 → 归档到题库 → 复盘 → 看分析 / 补学习清单
```

1. 在 **公司** 里先建目标公司（也可在新增岗位时直接新建公司）。
2. 在 **岗位** 里录入 JD、薪资、优先级，并把状态拖到当前阶段。
3. 收到面试邀约后，在 **面试** 或 **日历** 里创建面试，勾选同步岗位状态。
4. 面试结束后进入详情页，把题目、自己的回答、评分记下来。
5. 把题目归档到 **题库**（自动匹配或手动合并）。
6. 写一份 **复盘**，把弱项和学习项带进下一场面试。
7. 在 **分析** 里看高频弱项，必要时打开大模型生成学习建议。
8. 在 **模拟面试** 里用 AI 进行完整模拟或项目深挖，结束后查看反馈并沉淀题目。

## 页面说明

### 总览 `/`

求职仪表盘：已投递 / 面试中 / Offer / 已结束数量、最近面试、即将到来的面试，以及优先复习的知识点。

顶部可用 `Ctrl+K`（Mac 为 `Cmd+K`）全局搜索公司、岗位、面试、题库与模拟会话。右上角 `+` 可快速新增岗位或面试。

### 岗位 `/jobs`

两种视图：

- **看板**：列对应求职阶段（已投递、简历通过、笔试、一面、二面、HR面、Offer、已结束），卡片可拖拽改状态。
- **表格**：适合筛选和批量查看。

新增岗位时填写公司、职位、薪资、地点、类型（算法 / 后端 / 全栈 / 前端 / 数据 / 其他）、优先级、标签和 JD。可勾选「同时创建面试」。

岗位可关联实际投递的具体简历版本；关联信息会自动显示在该岗位的所有面试中。

### 简历 `/resumes` 与 `/resumes/:id`

可维护多套简历和共享项目库。每套简历通过「基于此版本新建」产生 v2、v3 等不可变版本，创建时会冻结所选项目内容。被岗位或模拟会话引用的版本只能归档，不能永久删除。

删除岗位会级联删除其下的面试、题目和复盘。

### 岗位详情 `/jobs/:id`

单个岗位的工作台：公司链接、状态 / 优先级 / 来源 / 投递日期、JD、面试时间线，以及编辑、新增面试、模拟面试、删除等快捷操作。

### 面试 `/interviews`

按时间列出全部面试，可按公司、轮次、状态筛选。

轮次：一面、二面、三面、HR面、加面、笔试。  
状态：待面试、已完成、等待反馈、已通过、未通过、已取消。

创建面试时可选择「同步岗位状态」（例如创建「一面」会把岗位推到对应阶段；仅前进不后退）。

### 面试详情 `/interviews/:id`

一场面试的工作台：

- 编辑基本信息、查看关联岗位 JD
- **添加问题**：题目、我的回答、反馈、理想答法、评分、标签
- 把某题标为弱项
- **归档到题库**：自动按相似度合并；不确定时可手动合并
- **学习清单**：本场要补的知识点，完成后勾选

### 复盘 `/review` 与 `/interviews/:id/review`

复盘列表展示尚未复盘 / 已复盘的面试。详情页可打分（整体、难度、技术匹配、岗位匹配），并填写做得好的地方、待改进、面试官关注点、常考题、下次准备。

未手动改过摘要时，系统会根据评分、弱项和学习清单自动生成总结。

### 日历 `/calendar`

月 / 周 / 日三种视图，每周起始日可在设置中切换（周一 / 周日）。点击某一天可直接在该日期创建面试。临近面试会有紧急程度标识。

### 题库 `/knowledge`

把重复出现的面试题沉淀成知识点。支持按分类、掌握程度、待复习筛选。

掌握程度：熟练 / 一般 / 不熟。列表上可用「记住了 / 模糊 / 忘了」快速记录复习结果（不熟 3 天、一般 7 天、熟练 21 天后再次提醒）。

分类可在 **设置 → 题库分类** 中自定义（默认含大模型方向示例）。

点击条目可编辑理想答案、我的答案、别名、来源题目。出现次数会随归档自动累计。

### 分析 `/insights`

基于已记录的问答统计：

- 高频考点、高弱项率标签
- 按轮次、公司的表现
- 评分趋势
- 学习优先级列表

可将前几条优先级一键加入「下一场面试」的学习清单。若已配置大模型，可生成 AI 学习建议。

### 公司 `/companies` 与 `/companies/:id`

维护公司档案（行业、地点、技术方向、评价、备注），详情页汇总该公司的岗位和面试。删除公司会级联删除其下岗位及关联数据。

### 模拟面试 `/mock`

两种模式，均调用设置里配置的 OpenAI 兼容大模型 API：

| 模式 | 说明 |
|------|------|
| **完整模拟** | 选择已有岗位，注入公司信息、JD、简历与项目，模拟真实面试流程 |
| **项目深挖** | 只勾选已录入的项目，面试官仅围绕这些项目追问 |

**使用步骤：**

1. 在 **设置** 中启用大模型并填写 Base URL、API Key、Model
2. 在模拟面试页 **上传简历**（PDF、Word `.docx`、Markdown、TXT、HTML，8MB 以内）。系统会解析文本并抽取摘要、教育、技能；若已配置大模型，还会尝试识别项目经历
3. 维护 **项目**（完整模拟至少需要简历或项目之一；项目深挖至少选一个项目）
4. 点击「开始模拟」，选择模式后开始多轮对话
5. 结束后点击「结束面试」，查看评分、优缺点与建议沉淀的问题
6. 可将建议问题一键加入 **题库**

岗位页（看板 / 表格）也支持「对该岗位模拟面试」，会预填岗位并打开完整模拟。

### 设置 `/settings`

| 区块 | 说明 |
|------|------|
| 个人设置 | 用户名、主题（浅色 / 深色 / 跟随系统）、每周起始日 |
| 题库分类 | 自定义分类与子分类 |
| 面试提醒 | 默认提前 1 天、1 小时；可选 3 小时、15 分钟。Toast 始终可用；浏览器通知仅在页面打开且已授权时生效 |
| 大模型 | OpenAI 兼容的 `/chat/completions`：Base URL、API Key、Model。用于同题判定、学习建议与模拟面试 |
| 数据管理 | 本地占用估算、清理已完成模拟会话、导出 JSON（会剔除 API Key）、覆盖/合并导入、重置 Demo、清空全部数据 |

「归档历史问题」会把尚未关联题库的面试题批量归档。

## 大模型（可选）

不配置也能完整使用。启用后主要用于：

1. 新题目与题库语义去重（模糊匹配不够时再调用）
2. 分析页生成学习建议
3. **模拟面试**（会把简历全文、项目描述与 JD 发往你配置的 API）

接口需兼容 OpenAI Chat Completions，例如：

```
Base URL: https://api.openai.com/v1
Model:    gpt-4o-mini
```

也可用其它兼容网关，只要提供 `POST {baseUrl}/chat/completions`。API Key 只存在本机，导出备份时会被剔除。

## 数据与隐私

- 存储键：浏览器 `localStorage`（Zustand persist）；配额不足时页面顶部会提示导出备份
- 模拟面试结束后仅保留最近 20 条已完成会话，可在设置中手动清理
- 换电脑 / 清缓存前请先在设置里 **Export Data**
- 导入可选 **覆盖**（替换现有数据）或 **合并**（按 id 合并）
- 全部在本地运行，面试内容不会上传，除非你主动调用了已配置的大模型 API
